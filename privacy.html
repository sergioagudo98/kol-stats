G-ON Stats Privacy Policy

Last updated: 27 October 2026

What the app accesses

When a content creator authorizes G-ON Stats with their Google account, the app requests read-only access to YouTube (scopes youtube.readonly and yt-analytics.readonly). It reads:

  • basic channel information (channel ID, name, subscriber count, list of uploaded videos);
  • aggregated YouTube Analytics metrics for the channel: views, likes, comments, shares, subscribers gained/lost, average view duration and percentage, and concurrent viewers of live streams.

The app does not read emails, contacts, comments' text, private messages or any other Google data, and it cannot upload, modify or delete anything.

How the data is used

The metrics are written, once a week, into the creator's internal performance report used by the Bitunix KOL team. They are used only to measure and improve the creator's content. The data is not sold, not used for advertising and not shared with third parties.

Storage and security

Only the authorization (refresh) token is stored, on a private server operated by the team, readable only by the service account running the tool. Aggregated metrics are stored in the internal report.

Revoking access and deletion

Creators can revoke access at any time at myaccount.google.com/permissions. On request, the stored token is deleted.

Google API Services User Data Policy

G-ON Stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy.
